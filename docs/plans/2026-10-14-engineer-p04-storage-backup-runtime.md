Before the first runtime slice, the integrator freezes these dependency handshakes:

1. **Protected reads and managed targets:** authenticate root-owned policy/configuration selections; return genuine current physical/namespace/configuration/Engine evidence, original expiry, complete consumer set and explicit unsupported reasons. Serialized summaries supply no effect authority. A consumes retained owners within their lifetimes and requests fresh evidence at effect time. Exact UUID/mountpoint/role/boot/swap ceilings bind targets; no caller path, arbitrary option, UID override or arbitrary executable is admitted. Existing target preparation remains separate from mount authority.
2. **Core/Store authority:** typed operation version, plan digest, current session/principal/grant revision, human approval, cancellation, idempotency replay, complete sorted physical/configuration/pool/share/protection/stack claims, atomic intent/dispatch/receipt/verification/terminal audit and recovery. `backup:*` logical requirements are insufficient alone. Schema 9 currently permits private backup jobs only Queued/Canceled and excludes dispatch: the integrator must deliver a reviewed migration/transition/dispatcher contract before A can run one. Replay does not repeat effects or adopt orphan directories.
3. **Executor/service contract:** fixed package-owned effect adapters, exact independent ceilings, peer authentication, bounded input/output/time, retained configuration selection, shared lock ordering, protected before-effect journal and receipts, current evidence recheck and independent result verification. Read worker registration/confinement is central; A must not replace it with an unsupervised subprocess. Ambiguous/dead/unverifiable effects retain claims and require explicit no-effect or verified reconciliation; failure is never success-shaped stdout.
4. **Stream B stack handshake:** one stable stack resource/claim identity across container lifecycle, deployment, backup and storage. B supplies complete owned-member resolution plus verified stop/quiesce/resume receipts; A supplies affected managed targets and before-image metadata. Stopped/unmanaged/nested/alias consumers stay visible. No planner assumes an empty declared list proves safe absence; neither stream fabricates a shutdown receipt. A backup/unmount touching stack data serializes with edits/restarts.
5. **API/UI/migration contract:** centrally registered GET-only status/preview reads and POST plan/approve/queue/cancel actions with CSRF and current authorization; immediate durable job response and reconnectable progress. Proposed storage/pool/protection/share/backup route families and operation versions are frozen by the integrator before code. A supplies generated-DTO consumers, required scope/limits, bounded safe failures, domain screens and preserved/unsupported import findings. Imports never edit old state or silently drop unknown settings; operation readiness is explicit. Central migration owns authoritative paths, metadata/ownership history, account changes and return compatibility.
